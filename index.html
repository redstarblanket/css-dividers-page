Animated Retro Star Divider

Animated

A sparkly retro divider with a shimmering gradient line, pulsing center star, and twinkling accents. Made with HTML and CSS only.

✦ ✧ ★ ✧ ✦

HTML

<div class="retro-divider" aria-hidden="true">
  <span class="divider-line left-line"></span>

  <span class="spark small-spark">✦</span>
  <span class="spark tiny-spark">✧</span>

  <span class="center-star">★</span>

  <span class="spark tiny-spark">✧</span>
  <span class="spark small-spark">✦</span>

  <span class="divider-line right-line"></span>
</div>

CSS

.retro-divider {
  width: min(700px, 90%);
  margin: 28px auto;

  display: flex;
  align-items: center;
  justify-content: center;

  gap: 10px;

  color: #ff89c6;
}

.divider-line {
  height: 2px;
  flex: 1;

  background-size: 200% 100%;

  animation:
    line-shimmer
    4s
    linear
    infinite;
}

.left-line {
  background-image:
    linear-gradient(
      to right,
      transparent,
      #ff89c6,
      #ffe6a7,
      #ff89c6
    );
}

.right-line {
  background-image:
    linear-gradient(
      to left,
      transparent,
      #ff89c6,
      #ffe6a7,
      #ff89c6
    );
}

@keyframes line-shimmer {
  from {
    background-position: 0% 50%;
  }

  to {
    background-position: 200% 50%;
  }
}

.center-star {
  display: inline-block;

  font-size: 34px;

  color: #ff89c6;

  text-shadow:
    0 0 6px rgba(255, 137, 198, 0.75),
    0 0 14px rgba(255, 137, 198, 0.35);

  animation:
    star-pulse
    2.2s
    ease-in-out
    infinite;
}

@keyframes star-pulse {
  0%,
  100% {
    transform: scale(1);
    opacity: 0.85;
  }

  50% {
    transform: scale(1.18);
    opacity: 1;
  }
}

.spark {
  display: inline-block;

  color: #ffd7ee;

  text-shadow:
    0 0 5px rgba(255, 215, 238, 0.7);

  animation:
    sparkle-twinkle
    1.8s
    ease-in-out
    infinite;
}

.small-spark {
  font-size: 15px;
}

.tiny-spark {
  font-size: 10px;
  animation-delay: 0.8s;
}

@keyframes sparkle-twinkle {
  0%,
  100% {
    opacity: 0.35;
    transform: scale(0.9);
  }

  50% {
    opacity: 1;
    transform: scale(1.25);
  }
}

@media (max-width: 500px) {
  .retro-divider {
    width: 90%;
    gap: 5px;
  }

  .center-star {
    font-size: 26px;
  }

  .small-spark {
    font-size: 11px;
  }

  .tiny-spark {
    font-size: 8px;
  }
}

@media (prefers-reduced-motion: reduce) {
  .divider-line,
  .center-star,
  .spark {
    animation: none;
  }
}
Customize it: Change #ff89c6 for the main pink color and #ffe6a7 for the highlight color.

Neon Glow Divider

Animated

A glowing neon divider with a pink, purple, and blue gradient and a softly pulsing center diamond. Made with HTML and CSS only.

◆

HTML

<div class="neon-divider" aria-hidden="true">
  <span class="neon-line"></span>
  <span class="neon-diamond">◆</span>
  <span class="neon-line"></span>
</div>

CSS

.neon-divider {
  width: min(700px, 90%);
  margin: 30px auto;

  display: flex;
  align-items: center;

  gap: 14px;
}

.neon-line {
  height: 2px;

  flex: 1;

  background:
    linear-gradient(
      to right,
      transparent,
      #ff4fd8 20%,
      #8c5cff 55%,
      #4bdcff 100%
    );

  box-shadow:
    0 0 5px rgba(255, 79, 216, 0.8),
    0 0 12px rgba(140, 92, 255, 0.55),
    0 0 20px rgba(75, 220, 255, 0.3);

  animation:
    neon-pulse
    2.4s
    ease-in-out
    infinite;
}

.neon-line:last-child {
  transform: scaleX(-1);
}

.neon-diamond {
  color: #ffffff;

  font-size: 16px;

  text-shadow:
    0 0 4px #ffffff,
    0 0 8px #ff4fd8,
    0 0 15px #8c5cff,
    0 0 24px #4bdcff;

  animation:
    neon-diamond-pulse
    2.4s
    ease-in-out
    infinite;
}

@keyframes neon-pulse {

  0%,
  100% {
    opacity: 0.65;

    filter: brightness(0.9);
  }

  50% {
    opacity: 1;

    filter: brightness(1.35);
  }

}

@keyframes neon-diamond-pulse {

  0%,
  100% {
    transform: scale(0.9);

    opacity: 0.8;
  }

  50% {
    transform: scale(1.15);

    opacity: 1;
  }

}

@media (prefers-reduced-motion: reduce) {

  .neon-line,
  .neon-diamond {
    animation: none;
  }

}
Customize it: Change #ff4fd8, #8c5cff, and #4bdcff to create your own neon gradient. Change 2.4s to adjust the animation speed. A larger number makes the glow pulse more slowly. You can also replace ◆ in the HTML with another text symbol such as ★, ✦, or ●.
